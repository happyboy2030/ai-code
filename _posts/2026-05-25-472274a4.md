# 深度学习基石：用PyTorch实现手写数字识别

## 从零搭建神经网络

### 引言：为什么需要深度学习？

想象一下，你正在教计算机识别手写的数字“3”。传统机器学习方法会让你手动提取特征：计算图像的像素分布、识别笔画方向、统计交叉点数量……这个过程不仅繁琐，而且对不同书写风格的数字往往效果不佳。更有趣的是，当数字“4”和“9”在特定写法下高度相似时，基于规则的方法几乎无能为力。

深度学习的革命性在于：它不再需要人类工程师手动设计特征，而是让模型自动从数据中学习最有区分力的特征表示。这种“端到端”的学习范式，通过层级化的特征提取，从像素级原始数据逐步抽象出高级语义信息，彻底改变了计算机视觉、自然语言处理等领域的格局。

今天，我们将用PyTorch这个强大的深度学习框架，从零搭建一个手写数字识别系统。即使你是深度学习新手，也能在本文中掌握核心概念和完整流程。

---

### 一、神经网络核心概念：从生物到数字的桥梁

在搭建模型之前，我们需要理解三个基础概念：

**1. 神经元：** 受生物神经元启发，人工神经元接收输入信号，加权求和后通过激活函数产生输出。数学上可以表示为：`output = activation(w1*x1 + w2*x2 + ... + b)`，其中w是权重，b是偏置。

**2. 激活函数：** 引入非线性能力。没有激活函数，多层网络等价于单层线性模型。常见的激活函数包括：
- ReLU（修正线性单元）：`f(x)=max(0,x)`，计算简单，缓解梯度消失
- Sigmoid：将值映射到(0,1)之间，适合二分类输出
- Softmax：将向量转换为概率分布，常用于多分类

**3. 层：** 将多个神经元组织成结构化的计算单元。全连接层（Dense Layer）中，每个神经元与前一层所有神经元相连，适合特征维度不高的场景；卷积层通过局部连接和权值共享，更适合图像这类具有空间结构的数据。

---

### 二、PyTorch环境搭建与张量基础

PyTorch（2016年由Facebook发布）凭借其动态计算图和简洁的Python API，已成为深度学习领域最受欢迎的框架之一。安装只需一行命令：

```bash
pip install torch torchvision
```

**张量（Tensor）**：PyTorch的核心数据结构，类似于NumPy的ndarray，但支持GPU加速和自动微分。基本操作示例：

```python
import torch

# 创建张量
x = torch.tensor([[1, 2], [3, 4.]])  # 从列表创建
y = torch.randn(3, 4)                # 标准正态分布随机矩阵

# 张量运算（自动支持GPU）
z = x @ x.T                          # 矩阵乘法
print(z.device)                      # 输出：cpu

# 转移到GPU（如果可用）
if torch.cuda.is_available():
    x = x.cuda()
    print(x.device)                  # 输出：cuda:0
```

**自动微分**：PyTorch最强大的特性之一。只需设置`requires_grad=True`，框架会自动记录所有运算，并在调用`.backward()`时计算梯度：

```python
w = torch.tensor([2.0], requires_grad=True)
y = w ** 2 + 3 * w + 1
y.backward()                         # 计算dy/dw
print(w.grad)                        # 输出：tensor([7.]) = 2*w + 3
```

### 三、MNIST数据集：深度学习界的“Hello World”

MNIST（Modified National Institute of Standards and Technology）包含70000张28x28像素的手写数字灰度图像，其中60000张用于训练，10000张用于测试。每个像素值在0-255之间，代表灰度强度。

虽然MNIST如今被认为过于简单，但它作为入门数据集具有无可替代的价值：
- 数据量适中，单张图像28x28=784维，训练速度快
- 10分类问题，评估指标直观
- 背景干净，数字居中，让初学者专注理解模型本身

加载MNIST数据非常简单，PyTorch的`torchvision`已经内置：

```python
import torchvision.transforms as transforms
from torch.utils.data import DataLoader
from torchvision.datasets import MNIST

# 定义数据预处理：转为张量并归一化到[0,1]
transform = transforms.Compose([
    transforms.ToTensor(),                         # 自动将PIL图像转为Tensor，值范围[0,1]
    transforms.Normalize((0.1307,), (0.3081,))     # MNIST的均值和标准差
])

# 下载并加载训练集
train_dataset = MNIST(root='./data', train=True, 
                      transform=transform, download=True)

# DataLoader实现批量加载和多线程预读
train_loader = DataLoader(train_dataset, batch_size=64, 
                          shuffle=True, num_workers=4)

# 同理加载测试集
test_dataset = MNIST(root='./data', train=False, 
                     transform=transform, download=True)
test_loader = DataLoader(test_dataset, batch_size=1000, 
                         shuffle=False, num_workers=4)
```

数据显示：每组数据包含图像张量（形状`[batch_size, 1, 28, 28]`）和标签（形状`[batch_size]`，值0-9）。

### 四、搭建全连接网络：从784维到10分类

我们将构建一个三层全连接网络，结构如下：

```
输入层 (784) → 隐藏层1 (128, ReLU) → 隐藏层2 (64, ReLU) → 输出层 (10, Softmax)
```

PyTorch通过`nn.Module`提供优雅的模型定义方式：

```python
import torch.nn as nn
import torch.nn.functional as F

class FullyConnectedNet(nn.Module):
    def __init__(self):
        super().__init__()
        # 定义层
        self.fc1 = nn.Linear(28*28, 128)   # 输入784→128
        self.fc2 = nn.Linear(128, 64)      # 128→64
        self.fc3 = nn.Linear(64, 10)       # 64→10
        
    def forward(self, x):
        # 前向传播：展开图像并逐层计算
        x = x.view(-1, 28*28)              # 展平为(batch, 784)
        x = F.relu(self.fc1(x))            # 隐藏层1 + ReLU
        x = F.relu(self.fc2(x))            # 隐藏层2 + ReLU
        x = self.fc3(x)                    # 输出层（logits）
        return x  # 注意：返回的是未归一化的logits

# 实例化模型
model = FullyConnectedNet()
print(model)
# 输出：
# FullyConnectedNet(
#   (fc1): Linear(in_features=784, out_features=128, bias=True)
#   (fc2): Linear(in_features=128, out_features=64, bias=True)
#   (fc3): Linear(in_features=64, out_features=10, bias=True)
# )
```

**为什么返回logits而不是Softmax概率？** 因为PyTorch的损失函数`CrossEntropyLoss`内部集成了Softmax，直接输入logits效率更高且数值更稳定。

### 五、训练过程：让模型学会识别数字

训练神经网络需要三个关键组件：

**1. 损失函数：** 衡量模型预测与真实标签的差距。对于多分类问题，使用交叉熵损失（CrossEntropyLoss）。

**2. 优化器：** 根据损失函数的梯度更新模型参数。Adam是常用的自适应优化器。

**3. 反向传播：** 自动计算梯度并更新参数。

完整的训练循环如下：

```python
import torch.optim as optim

# 初始化损失函数和优化器
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 训练参数
num_epochs = 5
train_losses = []  # 记录损失用于可视化

for epoch in range(num_epochs):
    model.train()  # 设为训练模式（启用Dropout等）
    running_loss = 0.0
    
    for images, labels in train_loader:
        # 前向传播
        outputs = model(images)                # 输入图像，得到logits
        loss = criterion(outputs, labels)      # 计算损失
        
        # 反向传播
        optimizer.zero_grad()                  # 清空上一轮梯度
        loss.backward()                        # 计算梯度
        optimizer.step()                       # 更新权重
        
        running_loss += loss.item() * images.size(0)
    
    # 计算每个epoch的平均损失
    epoch_loss = running_loss / len(train_loader.dataset)
    train_losses.append(epoch_loss)
    print(f'Epoch [{epoch+1}/{num_epochs}], Loss: {epoch_loss:.4f}')
```

训练结束后，我们可以绘制损失曲线观察模型收敛情况：

```python
import matplotlib.pyplot as plt

plt.plot(range(1, num_epochs+1), train_losses, marker='o')
plt.xlabel('Epoch')
plt.ylabel('Training Loss')
plt.title('Loss Curve')
plt.grid(True)
plt.show()
```

正常情况下，损失应从初始值（~2.3）快速下降到0.2以下。

### 六、测试与可视化：评估模型并分析错误

训练完成后，在测试集上评估模型性能：

```python
def evaluate(model, test_loader):
    model.eval()  # 设为评估模式
    correct = 0
    total = 0
    all_predictions = []
    all_labels = []
    all_images = []
    
    with torch.no_grad():  # 禁用梯度计算，节省内存
        for images, labels in test_loader:
            outputs = model(images)
            _, predicted = torch.max(outputs.data, 1)  # 取最大概率的索引
            total += labels.size(0)
            correct += (predicted == labels).sum().item()
            
            # 记录前100个样本用于可视化
            if len(all_images) < 100:
                all_images.append(images)
                all_labels.extend(labels.tolist())
                all_predictions.extend(predicted.tolist())
    
    accuracy = 100 * correct / total
    print(f'Test Accuracy: {accuracy:.2f}%')
    return accuracy, all_images, all_labels, all_predictions

test_accuracy, images_coll, true_labels, pred_labels = evaluate(model, test_loader)
```

全连接网络在MNIST上通常能达到97-98%的准确率。但更有价值的是分析那些被错误分类的样本：

```python
def visualize_errors(images, true_labels, pred_labels, num_errors=10):
    # 找出错误分类的索引
    error_indices = [i for i, (t, p) in enumerate(zip(true_labels, pred_labels)) if t != p]
    
    # 准备图像数据（需要反归一化）
    images_tensor = torch.cat(images_coll, dim=0)
    
    plt.figure(figsize=(12, 6))
    for i, idx in enumerate(error_indices[:num_errors]):
        plt.subplot(2, 5, i+1)
        img = images_tensor[idx].squeeze().numpy()
        plt.imshow(img, cmap='gray')
        plt.title(f'True: {true_labels[idx]}, Pred: {pred_labels[idx]}')
        plt.axis('off')
    plt.tight_layout()
    plt.show()

visualize_errors(images_coll, true_labels, pred_labels)
```

观察错误样例，你会发现模型容易混淆的数字对包括：4和9（形状相似）、7和2（倾斜角度）、3和8（闭合程度）。这些失败案例为我们提供了改进方向。

### 七、拓展：卷积网络带来质的飞跃

全连接网络忽略了图像的空间结构——它把每个像素当作独立特征，没有利用“相邻像素相关性更大”这一先验知识。卷积神经网络（CNN）通过**局部连接**和**权值共享**，完美解决了这个问题。

**卷积层的关键设计：**
- **感受野（Receptive Field）：** 每个卷积核只关注局部区域（如3x3），捕获边缘、纹理等低级特征
- **参数共享：** 同一个卷积核在图像上滑动，检测相同模式
- **池化层：** 下采样降低特征维度，同时提升特征不变性

下面是将全连接网络升级为CNN的完整实现：

```python
class ConvNet(nn.Module):
    def __init__(self):
        super().__init__()
        # 卷积部分
        self.conv1 = nn.Conv2d(1, 32, kernel_size=3, padding=1)  # 输入1通道，输出32通道
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)                           # 2x2池化
        
        # 全连接部分（分类头）
        self.fc1 = nn.Linear(64 * 7 * 7, 256)                    # 图像尺寸从28→14→7
        self.fc2 = nn.Linear(256, 10)
        self.dropout = nn.Dropout(0.5)                           # 防止过拟合
        
    def forward(self, x):
        # 卷积特征提取
        x = self.pool(F.relu(self.conv1(x)))    # 28x28 → 14x14 (32通道)
        x = self.pool(F.relu(self.conv2(x)))    # 14x14 → 7x7 (64通道)
        
        # 展平后全连接分类
        x = x.view(-1, 64 * 7 * 7)
        x = F.relu(self.fc1(x))
        x = self.dropout(x)                     # 训练时随机丢弃部分神经元
        x = self.fc2(x)
        return x

# 训练CNN（与全连接网络流程相同）
cnn_model = ConvNet()
cnn_optimizer = optim.Adam(cnn_model.parameters(), lr=0.001)
# 其余训练代码完全复用...
```

经过5个epoch训练，CNN的测试准确率通常能达到99%以上，显著优于全连接网络的97-98%。这印证了卷积结构对图像数据天然的优势——自动学习层次化的空间特征，从边缘到纹理再到局部形状，最终组合成完整数字的识别。

### 结语：从手写数字到无限可能

通过这个手写数字识别项目，我们走通了深度学习的完整流程：**数据准备 → 模型定义 → 损失函数 → 优化器 → 训练 → 评估 → 改进**。虽然MNIST是入门级数据集，但其中的核心概念——自动特征学习、梯度下降、层次化表示——适用于任何深度学习任务。

从全连接网络到卷积网络，我们见证了架构创新带来的性能飞跃。这仅仅是开始：你可以尝试更深的ResNet、轻量级的MobileNet，甚至将模型部署到移动设备。手写数字识别的完成，不是结束，而是你探索深度学习世界的起点。
